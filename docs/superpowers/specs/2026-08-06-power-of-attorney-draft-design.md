# Обезличенный шаблон доверенности DOCX

## Назначение

Создать редактируемый DOCX на основе структуры предоставленного пользователем документа. Итоговый файл предназначен для заполнения реквизитами, которые пользователь сообщит в диалоге. Неизменяемые формулировки, пунктуация, абзацы и оформление исходника сохраняются буквально.

## Состав документа

- Заголовок «ДОВЕРЕННОСТЬ» по центру.
- Строка города и даты выдачи.
- Блок данных доверителя.
- Блок данных представителя.
- Текст полномочий для обращения в ГБУ МФЦ города Москвы и проставления апостиля.
- Условия передоверия, срока и подписи.

## Оформление

Используются деловое выравнивание, отступы и абзацная структура исходного документа. В начальном варианте персональные данные отсутствуют. После получения данных они подставляются только в соответствующие реквизиты.

## Проверка

Проверить, что DOCX открывается, содержит все разделы и не содержит данных из исходной доверенности.
