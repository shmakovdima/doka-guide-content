# Обезличенный шаблон доверенности DOCX

## Назначение

Создать редактируемый черновик доверенности в формате DOCX на основе структуры предоставленного пользователем документа. Итоговый файл предназначен для заполнения реквизитами, которые пользователь сообщит в диалоге.

## Состав документа

- Заголовок «ДОВЕРЕННОСТЬ» по центру.
- Строка города и даты выдачи.
- Блок данных доверителя.
- Блок данных представителя.
- Текст полномочий для обращения в ГБУ МФЦ города Москвы и проставления апостиля.
- Условия передоверия, срока и подписи.
- Примечание «Черновик - заполнить и оформить в установленном порядке».

## Оформление

Используются деловое выравнивание, отступы и абзацная структура, близкие к исходному документу. В начальном варианте персональные данные отсутствуют. После получения данных они подставляются только в обозначенные поля.

## Проверка

Проверить, что DOCX открывается, содержит все разделы, не содержит данных из исходной доверенности и включает примечание о статусе черновика.
